# Data

The datasets used in this project are not included directly in the repository.

## Data Sources

- U.S. Data Jobs Salaries Dataset — Kaggle
- Bureau of Labor Statistics Occupational Employment and Wage Statistics
- Bureau of Economic Analysis Personal Consumption Expenditures by State

Raw datasets should be placed in:

`data/raw/`

Processed datasets generated by the notebooks are stored in:

`data/cleaned/`
